# 🔐 Oracle Vault

A secure, modern password manager built with React + Electron.

---

## 🚀 Features

* 🔐 AES encrypted vault
* 🧠 Master password protection
* 📱 Works on Desktop + Android (PWA)
* 💾 Export / Import backup (.ovault)
* 🧩 Categories (Websites, Apps, Cards, Notes)
* 🎨 Modern futuristic UI

---

## 📦 Tech Stack

* React + Vite
* Tailwind CSS
* Electron
* Web Crypto API

---

## 📱 Mobile Support

Install as PWA:

* Open in browser
* Add to home screen

---

## 🔒 Security

* All data is encrypted using AES-GCM
* Master password never stored
* Offline-first design

---

## ⚙️ Setup

```bash
npm install
npm run dev
```

---

## 🖥 Build

```bash
npm run build
npm run dist
```
